以坐标为列所构成的矩阵提供了一种描述线性变换的语言, 向量与矩阵相乘就是将线性变换作用于那个向量
类比于复合函数$f(g(x))\neq g(f(x))$, 两个矩阵相乘得到复合矩阵, 所以矩阵乘法没有交换律

| $(AB)^{-1}=B^{-1}A^{-1}$  | $(A^{-1})^\top=(A^\top)^{-1}$ | $(A+B)^\top=A^\top+B^\top$ |
| ------------------------- | ----------------------------- | -------------------------- |
| $(AB)^\top=B^\top A^\top$ | $(A^{-1})^*=(A^*)^{-1}$       |                            |
| $(AB)^*=B^*A^*$           | $(A^\top)^*=(A^*)^\top$       |                            |

# 转置矩阵

1. $(A^\top)^\top=A$
2. $(kA)^\top=kA^\top$
3. $(A+B)^\top=A^\top+B^\top$
4. $(AB)^\top=B^\top A^\top$

# 逆矩阵

[【熟肉】线性代数的本质 - 06 - 逆矩阵、列空间与零空间](https://www.bilibili.com/video/BV1ns411r7dE?spm_id_from=333.788.recommend_more_video.-1&trackid=web_related_0.router-related-2206146-mbfvr.1762787244811.69&vd_source=efaa5a93ee1b4d08289c38caae745794)
如果将矩阵看作是函数, 则逆矩阵就是反函数, E则是幺元, $AA^{-1}=A^{-1}A=E$
如果一个矩阵的行列式为0, 说明该矩阵将原来的向量组降维了, 但是没有任何一种线性变换能够用升维, 也就是降维操作是不可逆的, 这也就是为什么行列式为0的矩阵没有逆矩阵

1. A可逆的充分必要条件是$|A|\neq0$
2. $(A^{-1})^{-1}=A$
3. $(kA)^{-1}={A^{-1}/K}$
4. $(AB)^{-1}=B^{-1}A^{-1}$
5. $(A^\top)^{-1}=(A^{-1})^\top$
6. $|A^{-1}|=|A|^{-1}$

## 副对角线分块矩阵的逆

$$\begin{align}
A&=\left[\begin{matrix}&&&A_1\\&&A_2&\\&\ddots&&\\A_s&&&\\\end{matrix}\right]\\
A^{-1}&=\left[\begin{matrix}&&&A_s^{-1}\\&&\ddots&\\&A_2^{-1}&&\\A_1^{-1}&&&\\\end{matrix}\right]\\
\end{align}$$

# 伴随矩阵

[[行列式#余子式与代数余子式]]

$$\begin{align}
A^*&=\left[\begin{matrix}A_{11}&A_{21}&A_{31}\\A_{12}&A_{22}&A_{32}\\A_{{13}}&A_{23}&A_{33}\end{matrix}\right]
\end{align}$$

1. $AA^*=A^*A=|A|E$
2. $A^*=|A|A^{-1}$: 当A可逆时, $A^*$与$A^{-1}$只差一个非零的倍数
3. $|A^*|=|A|^{n-1}$
4. $(A^*)^\top=({A^\top})^*$
5. $(A^{-1})^\top=({A^\top})^{-1}$
6. $(AB)^*=B^*A^*$

当$|A|\neq0$时:
1. $A^*=|A|A^{-1}$
2. $(kA)(kA)^*=|kA|E$
3. $(A^\top)(A^\top)^*=|A^\top|E$
4. $(A^{-1})(A^{-1})^*=|A^{-1}|E$
5. $(A^*)(A^*)^*=|A^*|E$

# 初等矩阵

1. 初等矩阵的转置仍是初等矩阵
2. $[E_i(k)]^{-1}=E_i(1/k),E_{ij}^{-1}=E_{ij},[E_{ij}(k)]^{-1}=E_{ij}(-k)$
3. 若A为可逆矩阵$\Longleftrightarrow A=P_1P_2\cdots P_s$, 即有限个初等矩阵的乘积

### 倍乘初等矩阵

> $E_i(k)$: 左乘A的第i行乘k, 右乘A的第i列乘k

+ $E_i^{-1}(k)=E_i(1/k)$
+ $E_i^n(k)=E_i(k^n)$


$$E_2(k)=\left[\begin{matrix}
1&0&0\\
0&k&0\\
0&0&1\\
\end{matrix}\right]\qquad
E_2^{-1}(k)=E_2(1/k)=\left[\begin{matrix}
1&0&0\\
0&1/k&0\\
0&0&1\\
\end{matrix}\right]
$$
### 互换初等矩阵

> $E_{ij}$: 左乘A的第i行与第j行互换, 右乘A的第i列与第j列互换

+ $E_{ij}^{-1}=E_{ij}$
+ $E_{ij}^n=E_{ij}^{n\%2}$

$$
E_{12}=\left[\begin{matrix}
0&1&0\\
1&0&0\\
0&0&1\\
\end{matrix}\right]\qquad
E_{12}^{-1}=E_{12}=\left[\begin{matrix}
0&1&0\\
1&0&0\\
0&0&1\\
\end{matrix}\right]\qquad
$$
### 倍加初等矩阵

>$E_{ij}(k)$: 左乘第j行的k倍加到第i行, 右乘第i列的k倍加到第j列

+ $E_{ij}^{-1}(k)=E_{ij}(-k)$
+ $E_{ij}^n(k)=E_{ij}(nk)$


$$
E_{31}(k)=\left[\begin{matrix}
1&0&0\\
0&1&0\\
k&0&1\\
\end{matrix}\right]\qquad
E_{31}^{-1}(k)=E_{31}(-k)=\left[\begin{matrix}
1&0&0\\
0&1&0\\
-k&0&1\\
\end{matrix}\right]
$$

# 用初等变换求逆矩阵

$$\begin{align}
[A\;\vdots\;E]\xrightarrow{初等行变换}[E\;\vdots\;A^{-1}]\\
\left[\begin{matrix}A\\E\end{matrix}\right]\xrightarrow{初等列变换}\left[\begin{matrix}E\\A^{-1}\end{matrix}\right]
\end{align}$$

# $A^n$

1. A是秩1方阵, $r(A)=1\Rightarrow A^n-[tr(A)]^{n-1}A$
2. 试算$A^2,A^3$等, 归纳出结果
3. $A^n=(B+C)^n$, 且满足$BC=CB$, 用二维展开式
	可分解为一个幂零矩阵和单位阵相加
